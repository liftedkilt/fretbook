"Greensleeves" is a traditional English song from the sixteenth century. It uses four chords: **Am**, **C**, **G** and **E**.

```fretbook:chord
name: Am
```

```fretbook:chord
name: G
```

```fretbook:chord
name: E
```

Play one chord per bar, in three beats (down on the first, two lighter strums after):

```fretbook:tab
|Am / / |C / / |G / / |E / / |
|Am / / |C / / |E / / |Am / / |
```

Let each chord ring until the next one. Slow down for the change from G to E.
